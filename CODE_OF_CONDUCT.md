# Code of Conduct

Oolong follows the [OWASP Code of Conduct](https://policy.owasp.org/operational/code-of-conduct).

It applies to everyone taking part in the project: in issues, pull requests, discussions, reviews, and any other project space or event, and when representing the project elsewhere.

## Reporting

If you experience or witness behaviour that violates the Code of Conduct, contact the project leaders, Pavel Shukhman ([@taleodor](https://github.com/taleodor), pavel.shukhman@owasp.org) and Matt Rutkowski ([@mrutkows](https://github.com/mrutkows)).

Reports are handled confidentially.

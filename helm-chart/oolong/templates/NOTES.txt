Oolong installed

This chart requires an explicit compatible server image (image={{ .Values.image }}).
The published 25.10.6 registry image does not implement /healthz or git snapshot reload.

The TEA API is unauthenticated. This chart is for a public catalog. For private content, require authentication at the ingress and do not expose the Service directly.
Artifact download redirects follow publisher http/https URLs only; that is not server-side SSRF.
Pagination requires PAGE_TOKEN_SECRET. This release uses Secret "{{ include "oolong.pageTokenSecretName" . }}" (key {{ .Values.pageTokenSecret.secretKey }}). The development fallback (PAGE_TOKEN_DEV_FALLBACK) is not set by this chart.
{{- if and .Values.pageTokenSecret.create (not .Values.pageTokenSecret.existingSecret) }}
The chart-managed Secret is re-rendered on upgrade and keeps its existing encoded value.
{{- else if .Values.pageTokenSecret.existingSecret }}
You supplied pageTokenSecret.existingSecret; ensure that Secret exists in namespace {{ .Release.Namespace }}.
{{- end }}
Server pods are labeled app.kubernetes.io/component=server and Git pods use component=git. kubectl logs deploy/{{ include "oolong.fullname" . }} selects only the server. If Helm reports a Deployment selector is immutable, delete the server and Git Deployments (keep the PVC) and upgrade again.

{{- if .Values.persistence.enabled }}
Content is read from the PVC at /app/src/content. An empty volume hides the image's bundled fixtures until you populate it or enable gitPod.
{{- else }}
The server uses the bundled fixtures baked into the image at /app/src/content.
{{- end }}

{{- if and .Values.gitPod.enabled .Values.persistence.enabled }}
Git sync accepts https:// remotes, and ssh remotes when gitPod.auth.type is ssh. Optional gitPod.allowedHosts is an exact hostname allowlist. Restrict Git-pod egress (NetworkPolicy or cluster egress) so internal and metadata destinations stay unreachable; hostname checks do not follow DNS changes or Git redirects.
{{- if eq .Values.gitPod.auth.type "token" }}
Git auth is token: Secret {{ .Values.gitPod.auth.existingSecret }} must exist in this namespace with the keys {{ .Values.gitPod.auth.token.usernameKey }} and {{ .Values.gitPod.auth.token.tokenKey }}. A rotated Secret is picked up without a restart. Use a read-only token scoped to the one repository.
{{- else if eq .Values.gitPod.auth.type "ssh" }}
Git auth is ssh: Secret {{ .Values.gitPod.auth.existingSecret }} must exist in this namespace with the key {{ .Values.gitPod.auth.ssh.privateKeyKey }}{{ if .Values.gitPod.auth.ssh.knownHostsKey }} and {{ .Values.gitPod.auth.ssh.knownHostsKey }}{{ end }}. Host keys are always verified against the known_hosts you supplied. Use a read-only deploy key for the one repository. A rotated Secret is picked up on a later sync without a restart.
{{- end }}
{{- end }}
